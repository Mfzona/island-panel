# Изменения

## 1.3.2

- Фоновый режим по умолчанию: без отображения поверх всех окон, случайного раскрытия по наведению и перехвата фокуса при запуске.
- Запуск сразу в компактном виде.
- Тёмные скруглённые подсказки с читаемым текстом вместо белых прямоугольников.

## 1.3.1

- Атомарное изменение размера и положения окна устраняет боковой рывок при раскрытии и сворачивании.
- Наведение во время анимации не запускает повторное раскрытие.

## 1.3.0

- Реальный спектр и волна системного звука; остановка анализа в скрытом виде.
- Полка папок и программ с родными значками Windows и перестановкой.
- Цвета плеера по обложке, круглая кнопка паузы и крупные карточки файлов.

## 1.2.0

- Микшер приложений через Windows Core Audio.
- Окно исключено из Alt+Tab и панели задач.
